# КРІП

Україномовний адаптивний сайт Коаліції Регіональних Ініціатив Полтавщини.
Контент і фотографії взято з наданого інформаційного документа. Перелік із 20 підписантів відображає стан на 14 листопада 2025 року, а не поточну кількість учасників.

## Розробка

Потрібен Node.js 22+ та npm.

```sh
npm ci
npm run dev -- --port 5173
```

## Збірка

```sh
npm run build
npm run preview -- --port 4173
```

Каталог `dist` можна розмістити на статичному хостингу. Сайт не потребує сервера баз даних чи секретів. Кнопки зв’язку ведуть у соціальні мережі коаліції. Шрифти завантажуються з Google Fonts; за відсутності доступу використовуються системні шрифти.

## Структура

- `index.html` — розділи й основний контент.
- `style.css` — оформлення та адаптація до мобільних екранів.
- `main.js` — мобільне меню та розгортання списку підписантів.
- `assets/` — фотографії з наданого документа.

Перед публікацією варто погодити візуальний стиль і актуальність інформації з командою КРІП. Блок про Тернопіль не включено, оскільки у вихідному документі немає опису події.
